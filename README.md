# VideoDubber
A software to dub videos from one language to another.

## Functionalities
* Audio extraction from Video
* Speech to text and Text to speech
* Audio to text (speech recognition) 
* Text translation with Multiple translation suggestions
* Text to Audio conversion
* Multiple Voices Option
* Vary pitch, speed and loudness
* Combine the new audio back to the Video
* Modern GUI
* Identify intonation, intent and emotions and expressing it as well
